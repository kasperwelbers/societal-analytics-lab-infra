# Our software

Besides running infrastructure, the lab develops open-source research software:

* **[AmCAT](./amcat.md)** (Amsterdam Content Analysis Toolkit): storing, managing, sharing and analysing research data.
* **[AnnoTinder](./annotinder.md):** annotating research data.

The lab runs its own servers of this software ([Hosted services](./servers/services.md)), and other research groups can host it themselves. This section only covers what matters for deploying it securely: how logins work ([Authentication standard](./auth.md)), which login provider to choose ([Authentication provider](./auth-install.md)), and how to move to another provider ([Migration guide](./auth-migration.md)). Installation instructions are in the repositories of the software itself.
